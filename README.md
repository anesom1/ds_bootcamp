# Manage Bootcamp

A simple Python command-line application for managing bootcamp students.

The program allows users to:

- Add students
- Remove students
- List all students
- Search for students
- Exit the program

Student data is stored in a text file (`bootcamp.txt`).

---

## Features

### Add Student
Add a new student by entering:

- Name
- Age
- Email address

The information is saved to `bootcamp.txt`.

### Remove Student
Remove a student by entering their name.

### List Students
Display all students currently stored in the file.

### Search Student
Search for a student by name.

### Exit
Close the program from the menu.
